# Прототип диктофона WeeklyWins

Прошивка рассчитана на YD-ESP32-23 2022-V1.3 с ESP32-S3-N8R2 и модуль INMP441. Она пишет моно WAV с частотой 16 кГц и сохраняет завершённые записи во флеш-памяти. iPhone скачивает аудио по Wi-Fi, сохраняет исходное время и ставит аудио в обычную очередь распознавания WeeklyWins.

## Подключение

Соедините контакты при отключённом питании. Используйте надписи на модуле, поскольку расположение контактов на разных переходниках может отличаться.

| Контакт INMP441 | Контакт YD-ESP32-23 |
| --- | --- |
| VDD | 3V3 |
| GND | GND |
| SCK (BCLK) | GPIO 7 |
| WS (LRCLK) | GPIO 8 |
| SD (DOUT) | GPIO 9 |
| L/R | GND (левый канал) |

Если на микрофонном модуле нет подтяжки, поставьте резистор 100 кОм между SD и GND. Если у модуля нет конденсатора между VDD и GND, поставьте 100 нФ рядом с модулем. Кнопка BOOT на GPIO 0 работает как кнопка записи после загрузки. Индикатор платы на GPIO 48 горит красным во время записи и янтарным при ошибке. [Спецификация INMP441](https://invensense.tdk.com/wp-content/uploads/2015/02/INMP441.pdf) · [Документация платы](https://github.com/vcc-gnd/YD-ESP32-S3/blob/main/README.md)

## Сборка

Сборка проверена с Arduino-ESP32 3.3.2. Из корня репозитория выполните:

```sh
arduino-cli compile --fqbn esp32:esp32:esp32s3:FlashSize=8M,PSRAM=enabled firmware/WeeklyWinsRecorder
```

Для прошивки используйте USB-C с надписью COM и ту же конфигурацию платы. В скетче своя таблица разделов для 8 МБ флеш-памяти. Перед первой прошивкой сохраните данные, если они нужны. После запуска в мониторе порта (115200 бод) появятся имя сети `WeeklyWins-…` и постоянный пароль этого экземпляра.

## Синхронизация и проверка

1. После подачи питания подключите iPhone к сети диктофона в настройках Wi-Fi. В WeeklyWins откройте «Настройки» → «Данные» → «Диктофон ESP32» и нажмите «Синхронизировать». Разрешите доступ к локальной сети. При первом запуске этот шаг выставляет часы.
2. Оставьте диктофон включённым, отключите iPhone от его сети. Нажмите BOOT, продиктуйте заметку, нажмите BOOT повторно. Красный индикатор горит только во время захвата. Запись автоматически завершается через 90 секунд или при заполнении отведённого места.
3. Подключитесь к Wi-Fi диктофона снова и синхронизируйте. В «Записях» проверьте время и воспроизведение, после распознавания найдите событие в ленте и отчёте за исходную дату рядом с заметкой, записанной на iPhone.
4. Повторите синхронизацию. Количество записей и событий должно остаться прежним. Для проверки обрыва повторите опыт и отключите Wi-Fi во время скачивания. При восстановлении связи повторная синхронизация должна получить запись один раз.

После полного отключения питания часы нужно выставить снова. Время уже сохранённых файлов остаётся прежним. Незавершённый WAV при внезапной потере питания отбрасывается при загрузке. Для автономной записи используйте непрерывное питание, например пауэрбанк.

Приложение получает список UUID и исходных дат, скачивает WAV по UUID и подтверждает импорт после сохранения аудио и записи в локальном журнале. Только после подтверждения диктофон освобождает место. Повтор после обрыва подтверждения распознаёт уже сохранённый UUID.
