# Дизайн: цветная кромка категории в карточках ленты дня

Дата: 2026-11-21
Статус: утверждено пользователем (вариант 2, ширина 6 pt)

## Зачем

Дела в ленте дня с разными категориями (Работа / Дом / Без категории) выглядят
одинаково: карточки отличаются только серой строкой метаданных. Пользователь
просил, чтобы расшифровки с разными категориями **слегка** отличались по цвету,
без изменения утверждённой формы карточек.

## Решение

Вариант 2 из обсуждения: цветная вертикальная кромка слева в карточке дела,
ширина **6 pt**, цвет — существующий `StudioTheme.categoryColor`:

- Работа → мята (`#B6E5CE`)
- Дом → песок (`#E9C889`)
- Без категории → нейтральный серый (`#B5BFBA`, как сейчас выглядит текст категории)

Текст дела и метаданные не меняются: цвет дублируется текстом категории,
различие считывается и без цвета (доступность не страдает). Метаданные
карточки на момент реализации — «Запись 9:41 · Работа» (хранение времени
дела и длительности удалено, см. `2026-11-21-remove-event-time-duration-design.md`).

## Где применяется

Только карточки дел ленты дня (`dayEventRow` / `eventDetails` в
`WeeklyWins/Reports/ReportView.swift`). Экран «Отчёты» за неделю/месяц карточек
не содержит (там текст для шаринга), экраны «События» и детали дела уже
используют цвет категории в тексте — их не трогаем.

## Детали реализации (договорённости и допущения)

- Кромка повторяет скругление карточки (радиус 16): полоса рисуется у левого
  края внутри уже существующего `clipShape`, поэтому скругление достигается
  обрезкой, отдельная форма со скруглением не нужна.
- Отступ от кромки до текста ~12 pt (как сейчас от края карточки до текста):
  полоса 6 pt + привычный отступ контента.
- Кромка — часть карточки: при свайпе удаления уезжает вместе с ней.
- Крупный системный текст (Dynamic Type): полоса фиксированной ширины,
  контраст не затрагивается — рисков нет.
- Accessibility: значение категории уже озвучивается в метаданных карточки,
  дополнительных меток не добавляем.

## Не-цели

- Не менять цвета текста, фона карточек и формы компонентов.
- Не добавлять кромку в отчёты, шеринг-текст, экран «События» и детали дела.
- Не вводить новых цветов в палитру.
