# Голосовая студия — три варианта расположения экранов

17 ноября 2026 года. Пользователь утвердил палитру «Голосовая студия» и вариант A «Лента дня». При реализации руководствоваться [утверждённым дизайном](approved-design.md) и [макетом A](layout-a-approved.png). Варианты B и C сохранены как рассмотренные предложения.

## Общая визуальная система

| Элемент | Цвет или правило |
| --- | --- |
| Основной фон | `#111515`, графит |
| Поверхности | `#1D2424` |
| Основной текст | `#F3F6F4` |
| Вторичный текст | `#B5BFBA` |
| Действия и выбранные элементы | `#B6E5CE`, мятный |
| Идущая запись, остановка, ошибка | `#FF7B6B`, коралловый |
| Работа | Мятная метка и значок портфеля |
| Дом | Песочная метка `#E9C889` и значок дома |
| Без категории | Нейтральная метка с текстом |
| Заголовки и основной текст | Системный шрифт iOS, поддержка увеличения размера |
| Таймер и длительности | Моноширинные цифры |

Кнопки имеют область нажатия от 44 × 44 pt. Важные действия расположены в нижней части экрана. Цвет категории сопровождается текстом и значком. В карточках ленты дня категория выделяется компактной цветной плашкой под текстом; карточка открывает детали по нажатию, аудиозапись доступна оттуда. В рабочем приложении фоновые состояния, системные панели и клавиатура используют нативные компоненты SwiftUI.

## Общие правила продукта

- Запись начинается одним нажатием кнопки в приложении или удержанием настроенной Action Button. Повторное удержание Action Button завершает запись.
- На экране записи всегда видны таймер, индикатор активности и остановка. Максимум — пять минут. По достижении лимита запись сохраняется.
- Сворачивание экрана записи сохраняет захват. На остальных экранах появляется компактная панель с таймером и кнопкой остановки. Открытие панели возвращает полный экран записи.
- Live Activity на заблокированном экране показывает «Идёт запись», таймер и состояние. Action Button остаётся способом остановки. Интерактивная остановка внутри Live Activity должна пройти отдельную техническую проверку перед включением.
- Сохранение аудио и обработка имеют отдельные статусы. После остановки пользователь может продолжить работу, пока выполняется расшифровка.
- Из расшифровки предлагаются события. Они доступны в хронологии сразу после успешного разбора. Проверка событий остаётся доступной позже.
- Время записи имеет явную подпись «Запись». Время дела и длительность не хранятся и не показываются.
- Категории «Работа», «Дом» и «Без категории» доступны во всех трёх вариантах. Неуверенные категории остаются для выбора пользователем.
- Текст события, категория и статус выполнения редактируются. Источник открывает аудиозапись и исходный фрагмент расшифровки.
- В отчёте показываются количество дел и количество выполненных. Длительности дел не хранятся и не суммируются.
- Изменение события сразу обновляет хронологию и отчёты. Пользовательские исправления сохраняются при повторной расшифровке.
- Удаление одного события предлагает «Отменить». На экране «Записи» свайп влево показывает действие удаления; нажатие удаляет аудио, расшифровку и связанные события без второго подтверждения.
- Редактор сохраняет черновик при уходе в фон. Закрытие изменённого редактора предлагает сохранить изменения или отбросить их.
- Экран настроек содержит версию и сборку. Частые действия доступны через основной интерфейс.

## Вариант A — Лента дня

### Основная навигация

Внизу три вкладки «Сегодня», «Записи», «Отчёты». На первом запуске после настройки открывается «Сегодня». В ленте дня круглый микрофон закреплён слева над вкладками поверх списка. При прокрутке его фон становится полупрозрачным. На остальных вкладках над вкладками закреплена широкая кнопка записи. При захвате видна коралловая панель состояния и остановки. В правой верхней части основных экранов находится кнопка настроек. [Утверждённое уточнение ленты](approved-design.md#сегодня-и-другой-день).

Основной цикл — открыть приложение → увидеть дела за день → записать дополнение → вернуться в обновлённую ленту.

| Экран | Расположение элементов и взаимодействия |
| --- | --- |
| A01. Первое открытие | Заголовок «Вспомнить свой день», короткий пример преобразования голоса в два дела. Внизу «Начать». На следующем шаге — «Проверить микрофон», системный запрос и пробная запись. Ссылка «Настроить кнопку действия» доступна после выдачи доступа. |
| A02. Сегодня | В шапке выбрана дата с календарём; стрелки предыдущего и следующего дня стоят по обе стороны от даты. Справа настройки. Под датой компактная сводка количества дел, затем фильтр «Все / Работа / Дом / Без категории». Карточки занимают ширину ленты; время записи и категория показаны на приглушённой цветной плашке внизу вторичным текстом. Карточка открывает детали по нажатию. Круглый микрофон наложен слева над вкладками. |
| A03. Другой день | Та же лента со стрелками по обе стороны выбранной даты; справа также доступна кнопка «Сегодня» для возврата к текущей дате. Круглый микрофон запускает запись с фактической текущей датой, затем приложение возвращает пользователя к выбранному дню. |
| A04. Запуск записи | Экран на весь доступный размер. Сверху «Запись», ниже краткое состояние подготовки. Кнопка старта блокируется до результата. Ошибка подготовки появляется здесь же с действием повторить. |
| A05. Идёт запись | Таймер крупно в верхней половине, под ним волна сигнала и подпись «Идёт запись». Внизу большая коралловая кнопка остановки. Сверху кнопка «Свернуть». Выбор категории остаётся на этапе событий. |
| A06. Сохранение и обработка | После остановки — короткое подтверждение «Аудио сохранено», затем возврат в ленту. Вверху ленты компактная строка «Расшифровывается запись 14:20». Нажатие открывает запись. |
| A07. Записи | Сверху заголовок, поиск по расшифровкам и датам. Далее секции по дням. Строка содержит время, длительность аудио и статус на нейтральной плашке внизу. Нажатие строки открывает детали. Свайп влево показывает «Удалить»; нажатие удаляет запись и связанные данные сразу. |
| A08. Детали аудиозаписи | Вверху дата и время записи. Затем плеер с таймлайном и воспроизведением. Ниже блок расшифровки, действия «Изменить текст» и «События». Системная кнопка «Назад» возвращает список. |
| A09. Редактор расшифровки | Сверху «Расшифровка», «Отмена» и «Сохранить». Текст занимает всё пространство над клавиатурой. Плеер свёрнут в компактную строку. Внизу клавиатуры доступно завершение редактирования. |
| A10. Проверка событий | Список компактных предложений событий, у каждого видны текст и категория на цветной нижней плашке, как в ленте. Нажатие раскрывает редактор. Внизу «Добавить дело» и «Готово». Объединение доступно через выбор двух соседних событий. |
| A11. Карточка события | Сверху текст дела и категория. Ниже время записи. Затем исходный фрагмент и ссылка на аудио. Действие «Изменить» открывает форму. |
| A12. Редактор события | Сначала текст дела, затем категория и статус выполнения. Внизу «Сохранить», в меню — удалить. Клавиатура не перекрывает сохранение. |
| A13. Отчёт за день | Вверху переключатель «День / Неделя / Месяц», ниже дата со стрелками. По умолчанию включён фильтр «Работа». Затем количество дел и выполненных. Ниже список событий. |
| A14. Отчёт за неделю | Сохраняет расположение A13. По умолчанию выбран фильтр «Работа». Вместо даты — диапазон недели. После сводки расположен график по семи дням. Нажатие столбца открывает выбранный дневной отчёт. |
| A15. Отчёт за месяц | Сохраняет расположение A13. В заголовке месяц и год. График по дням месяца прокручивается, либо отображается компактный календарь. Нажатие дня открывает дневной отчёт. |
| A16. Выбор даты и фильтров | Календарь открывается нижней панелью. Категории переключаются на текущем экране и видны в заголовке списка. «Сбросить» возвращает полный список выбранного периода. |
| A17. Объединение событий | Нижняя панель показывает два исходных текста и итоговое редактируемое поле. Категория и статус подтверждаются пользователем. Внизу «Объединить», сверху закрытие. |
| A18. Настройки | Список «Микрофон», «Офлайн-распознавание», «Кнопка действия», «Версия и сборка». Настройка кнопки содержит пошаговую инструкцию и проверочный запуск. Доступы ведут в системные настройки при отказе. |

### Состояния A

| Состояние | Представление |
| --- | --- |
| Сегодня пусто | Вместо ленты короткая подсказка «Расскажите, что уже сделали». Круглый микрофон остаётся слева над вкладками. |
| Есть аудио без расшифровки | Строка обработки над лентой и доступ к записи во вкладке «Записи». |
| Расшифровка не удалась | Строка с ошибкой и «Повторить». Детали записи содержат плеер и ручной ввод текста. |
| Найдено несколько событий | Новые строки появляются в ленте, рядом компактное действие «Проверить». |
| Идёт запись при просмотре отчёта | Над вкладками закреплена коралловая панель с таймером и остановкой. |
| Ошибка сохранения правки | Ошибка возле кнопки сохранения, черновик остаётся в редакторе. |
| Нет данных в отчёте | Сохраняются период, дата и категории. Вместо графика — «За этот период нет событий». |

**Удобство.** Подходит для просмотра дня и коротких дополнений в течение дня. В ленте ручная запись доступна одним нажатием на круглый микрофон. До аудиозаписи из события нужен один переход.

## Вариант B — Диктофон

### Основная навигация

Внизу вкладки «Запись», «Дела», «Отчёты». При открытии приложения показывается «Запись». Верхняя половина этого экрана отведена под состояние микрофона, нижняя — под большую кнопку записи и последние аудиозаметки. Экран «Дела» хранит хронологию и категории.

Основной цикл — открыть приложение → записать → увидеть расшифровку и предложенные дела → продолжить день.

| Экран | Расположение элементов и взаимодействия |
| --- | --- |
| B01. Первое открытие | Короткий экран о записи голоса, внизу «Настроить микрофон». После выдачи доступа открывается главный диктофон. Пробная запись использует обычный экран и может быть удалена после прослушивания. |
| B02. Главный диктофон | Сверху «Запись» и настройки. В центре нейтральная волна и подпись «Готово». Ниже большая круглая мятная кнопка микрофона с подписью «Записать». Под ней последние три записи, в заголовке секции ссылка «Все записи». |
| B03. Запуск записи | Остаётся на B02. Микрофон меняет состояние на подготовку, повторный запуск блокируется. Список последних записей остаётся доступным после подготовки. |
| B04. Идёт запись | Верхняя половина показывает крупный таймер и волну. Кнопка микрофона становится коралловой остановкой с квадратом. Нижний список сменяется компактной подписью о максимальных пяти минутах. Вкладки доступны. |
| B05. Сохранено и обрабатывается | На B02 появляется последняя запись со статусом расшифровки. Большая кнопка снова готова к следующей записи. Завершённая расшифровка открывается нажатием строки. |
| B06. Все записи | Отдельный экран из B02. Вверху поиск и фильтр периода, затем список с длительностью аудио и состоянием. Кнопка «Назад» возвращает диктофон. Внизу компактная кнопка записи. |
| B07. Детали записи | Вверху большой плеер и длительность аудио. Под ним переключатель «Текст / Дела». «Текст» показывает расшифровку, «Дела» — события из этой записи. Повторная расшифровка находится в меню записи. |
| B08. Редактор текста | Открывается из раздела «Текст». Сверху «Сохранить», ниже весь текст. Плеер остаётся компактным над клавиатурой. После сохранения возврат к B07 в тот же раздел. |
| B09. Проверка дел записи | Раздел «Дела» внутри B07. Каждое дело — компактная карточка с выбором категории. Внизу «Добавить» и «Готово». Выбор карточки открывает полный редактор. |
| B10. Все дела за день | Вкладка «Дела». Сверху дата со стрелками и календарём. Под ней фильтр категорий. Основная область — список событий. Внизу при захвате отображается компактная запись с остановкой. |
| B11. Карточка дела | Открывается из B10 или отчёта. Сначала текст и категория, затем необязательные время и длительность. Исходная запись находится внизу с кнопкой воспроизведения и переходом в B07. |
| B12. Редактор дела | Нижняя полноразмерная панель. Текст вверху, категории крупным выбором ниже. Затем статус выполнения, время и длительность. Внизу сохранение, удаление — в меню. |
| B13. Объединение | Из раздела «Дела» записи включается выбор нескольких событий. Нижняя панель содержит итоговый текст и подтверждение метаданных. Сохранение возвращает B09. |
| B14. Дневной отчёт | Вкладка «Отчёты». Сверху период и дата. Сводка по работе и дому, ниже список событий выбранного дня. Нажатие события открывает B11. |
| B15. Недельный отчёт | На B14 выбирается «Неделя». Диапазон недели, график известных длительностей по дням, категории и число событий. Нажатие дня переключает отчёт на день. |
| B16. Месячный отчёт | На B14 выбирается «Месяц». Месяц и год, календарь с количеством событий по дням, сводка категорий и список. Выбор дня открывает дневной отчёт. |
| B17. Дата и фильтры | Календарь появляется снизу над текущей вкладкой. Категория выбирается на экране дел или отчёта. В списке аудио фильтр показывает записи, содержащие события выбранной категории. |
| B18. Настройки | Открываются с главного диктофона и доступны из меню других вкладок. Содержат доступы, состояние офлайн-модели, настройку Action Button и версию. Возврат восстанавливает прежний экран. |

### Состояния B

| Состояние | Представление |
| --- | --- |
| Записей ещё нет | Под кнопкой микрофона один пример того, что можно сказать. Секция последних записей отсутствует. |
| Идёт запись во вкладке «Дела» | Мини-панель над вкладками. Нажатие возвращает главный диктофон, остановка доступна отдельно. |
| Обработка нескольких записей | У каждой строки свой статус. Общая кнопка записи остаётся доступной. |
| Расшифровка не удалась | Ошибка внутри последней записи и в B07. «Повторить» рядом со статусом, аудио доступно. |
| События ещё не проверены | Метка «Проверить дела» на записи ведёт сразу в раздел «Дела». |
| Дел за дату нет | Пустой список во вкладке «Дела», дата и фильтр сохраняются. Быстрый переход «Записать» ведёт на B02. |
| Сохранение редактора не удалось | Ошибка внутри нижней панели, введённые значения сохраняются. |

**Удобство.** Подходит для частых голосовых заметок. Запуск записи занимает одно нажатие после открытия приложения. Просмотр дня требует перехода во вкладку «Дела».

## Вариант C — Единый день

### Основная навигация

Внизу две вкладки «Дневник» и «Обзор». Над ними компактная панель с кнопкой «Записать». «Дневник» объединяет события и связанные аудиозаписи за выбранный день. Вверху горизонтальная полоса дат. Плеер, расшифровка и редакторы открываются нижними панелями поверх выбранного дня.

Основной цикл — выбрать день → просмотреть события и записи вместе → раскрыть нужную запись → исправить события на месте.

| Экран | Расположение элементов и взаимодействия |
| --- | --- |
| C01. Первое открытие | Пример одного дня с одной голосовой заметкой и двумя делами. Внизу «Начать дневник». Настройка микрофона открывается при первой записи. Инструкция Action Button доступна сразу после разрешения. |
| C02. День в дневнике | Сверху заголовок выбранной даты, настройки и кнопка календаря. Под ним горизонтальная неделя, затем фильтр категорий. Ниже хронология событий и компактные строки аудиоисточников. Внизу закреплена «Записать». |
| C03. Архив дней | Календарь в нижней панели. Под выбранным месяцем список дней с количеством событий. Выбор дня закрывает панель и обновляет C02. «Сегодня» всегда доступно в заголовке. |
| C04. Запуск записи | По нажатию нижней кнопки раскрывается панель до средней высоты. Состояние подготовки и заблокированный микрофон. День остаётся видимым за панелью. |
| C05. Идёт запись | Панель раскрывается до большой высоты. Крупный таймер, волна и большая остановка. Свайп вниз переводит её в закреплённую мини-панель. Остановка доступна в обоих размерах. |
| C06. Сохранено и обработка | В C02 появляется строка аудио с фактическим временем записи и статусом. Панель захвата закрывается. После обработки рядом появляются события этой записи. |
| C07. Аудиозаписи дня | Переключатель «Дела / Аудио» под полосой дат меняет содержимое выбранного дня. В «Аудио» строки сгруппированы по времени записи. Глобальный архив открывается поиском с выбором диапазона. |
| C08. Детали записи | Нижняя панель над C02. Сверху плеер и время записи. Ниже расшифровка и связанные события. Потянуть панель вверх можно для чтения длинного текста. |
| C09. Редактор расшифровки | Панель раскрывается на весь экран. Вверху «Закрыть» и «Сохранить», в центре текст, над клавиатурой компактный плеер. После сохранения панель возвращается к деталям записи. |
| C10. Проверка событий | Внутри C08 блок «Дела из записи» раскрывается в список. Категории выбираются прямо в строках. Под списком «Добавить дело», сверху «Готово». Для текста и метаданных открывается редактор. |
| C11. Карточка события | Нажатие события в C02 открывает нижнюю панель. Сверху текст и категория, затем время и длительность. Ниже исходный фрагмент и переход к C08. Фон сохраняет положение в дневнике. |
| C12. Редактор события | Большая нижняя панель. Сверху текст, затем категория и статус. Время и длительность открываются дополнительными строками. Сохранение закреплено внизу, удаление доступно в меню. |
| C13. Объединение | В C10 включается выбор событий одной записи. Итог открывается новой панелью с текстом и подтверждением метаданных. Возврат сохраняет выбранный день и положение списка. |
| C14. Дневной обзор | Вкладка «Обзор». Сверху период и дата. Сводка категорий и известных длительностей, ниже компактный список дел. Переход к событию открывает C11 поверх обзора. |
| C15. Недельный обзор | В C14 выбирается неделя. Сначала диапазон, затем график по дням и категории. Выбор дня переключает вкладку «Дневник» на выбранную дату, кнопка «Назад к обзору» возвращает период. |
| C16. Месячный обзор | В C14 выбирается месяц. Календарная сетка с числами событий и сводка категорий. Нажатие дня ведёт в дневник. Месяц обзора сохраняется при возврате. |
| C17. Поиск и фильтры | Поиск открывается из заголовка дневника отдельным экраном. Сверху строка поиска, ниже период и категории. Результаты объединяют события и аудиозаписи с подписями типа. |
| C18. Настройки | Нижняя панель из заголовка дневника или обзора. Доступы, офлайн-модель, Action Button и версия. Длинная инструкция открывается отдельным экраном внутри панели. |

### Состояния C

| Состояние | Представление |
| --- | --- |
| Пустой день | Полоса дат остаётся вверху, в центре «За этот день ещё нет записей». Нижняя кнопка записи сохраняется. |
| Аудио есть, событий нет | Строка аудио находится в хронологии. Она раскрывает расшифровку и действие обработки. |
| Несколько необработанных записей | Каждая строка показывает свой статус, раскрывается независимо. |
| Идёт запись при выборе другой даты | Компактная панель захвата остаётся над вкладками. Дата захвата сохраняется по текущему времени. |
| Ошибка расшифровки | Ошибка у строки аудио и внутри C08, там же повтор и ручное редактирование. |
| Клавиатура открыта | Редактор раскрывается до полной высоты, сохранение находится над клавиатурой. Дневник остаётся под панелью. |
| Не удалось сохранить событие | Ошибка внутри редактора, панель остаётся открытой с черновиком. |

**Удобство.** Подходит для возвращения к прошлым дням и работы с исходными записями. Экран сохраняет контекст дня при чтении и исправлениях. Потребуется особенно тщательно проверить поведение вложенных панелей и клавиатуры.

Предпочтительный вариант для исходной задачи — A. Лента дня. Он делает просмотр сделанного основным экраном и сохраняет быстрый запуск записи. Вариант B стоит выбрать при приоритете частых голосовых заметок. Вариант C подходит при частом просмотре прошлых дней и необходимости работать с аудио в контексте дня.

Макеты показывают ключевые экраны и иллюстративные данные. Детальная спецификация выше определяет поведение всех экранов при реализации. После выбора необходимо проверить выбранную схему в симуляторе на штатном и увеличенном размере текста, длинных русских названиях и открытой клавиатуре.
