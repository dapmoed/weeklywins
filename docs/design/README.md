# Варианты оформления WeeklyWins

Три визуальных направления для выбора пользователем. Макеты созданы 17 ноября 2026 года. Данные на экранах иллюстративные. Каждый вариант показывает «Сегодня» и недельный отчёт с панелью активной записи.

| Вариант | Характер | Файл |
| --- | --- | --- |
| 1. Тихий дневник | Тёплый светлый фон, зелёные акценты, выразительная типографика | [Макет](01-quiet-journal.png) |
| 2. Голосовая студия | Тёмные поверхности, мятные акценты, заметные таймер и волна записи | [Макет](02-voice-studio.png) |
| 3. Карта дня | Цветная хронология, различимые категории, наглядный отчёт | [Макет](03-day-map.png) |

После выбора проработать запись, расшифровку, редактор событий, пустые состояния и ошибки в едином стиле. Уточнить доступность при крупном системном шрифте, контраст и минимальные размеры элементов. Время события показывать только при наличии, иначе явно подписывать время записи. Длительность аудио и длительность дела имеют разные подписи. Графики должны отображать фактические данные приложения. Числа и подписи в иллюстрациях требуют сверки при реализации.

Визуальный ориентир для дневника и хронологии — [Apple Journal](https://www.apple.com/newsroom/2023/12/apple-launches-journal-app-a-new-app-for-reflecting-on-everyday-moments/). Варианты подготовлены для текущего SwiftUI-приложения с записью через Action Button, локальной расшифровкой и категориями «Работа» и «Дом».

Выбор пользователя ожидается.
