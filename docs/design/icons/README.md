# Иконка WeeklyWins

17 ноября 2026 года пользователь выбрал направление 3 «Эхо». Мятная W-волна с коралловой точкой на графитовом фоне продолжает палитру «Голосовой студии».

## Рассмотренные направления

- [Голос](01-voice.png) — микрофон из звуковой волны.
- [Лента дня](02-timeline.png) — хронология событий.
- [Эхо, выбранное направление](03-echo-selected.png) — W-волна.
- [Первое сравнение на домашнем экране](initial-homescreen-comparison.png).

## Вариации «Эхо» для выбора

- [Исходный вариант](03-echo-selected.png) — округлая W-волна.
- [A «Плавная»](echo-a-smooth.png) — тонкая симметричная линия.
- [B «Геометрия»](echo-b-geometric.png) — выраженные диагонали и округлённые углы W.
- [C «Ритм»](echo-c-rhythm.png) — асимметричная волна с разной глубиной впадин.
- [Сравнение четырёх вариантов на домашнем экране](echo-homescreen-comparison.png).

Контекстные изображения созданы ImageGen на основе скриншота домашнего экрана симулятора, его обоев и сетки приложений. Это визуальные макеты. Пользователь выбрал вариант C «Ритм» и запросил добавление объёма.

При дальнейшей презентации показывать иконку на фоне домашнего экрана телефона, рядом с другими приложениями и в обычном размере.

## Выбранный C с объёмом

- [Объёмная проработка](echo-c-volume.png) добавляет скруглённую толщину, верхний свет, мягкую тень и объёмную коралловую точку.
- [Фактический домашний экран iOS Simulator](echo-c-volume-simulator.png) показывает установленный вариант «Эхо C объём» рядом с плоским C. Снимок получен через simctl на iPhone 17 Pro с iOS 26.5.
- [Фактическое сравнение четырёх исходных вариаций](echo-simulator-home-screen.png) снято до добавления объёмной проработки.

Для проверки системного отображения подготовлены отдельные временные приложения просмотра иконок с идентификаторами com.weeklywins.iconpreview.*. После подключения иконки к WeeklyWins временные приложения удалены из симулятора. Артефакты сборки находятся в /private/tmp/weeklywins-icon-preview-20261117. Скриншоты с именем simulator получены из iOS Simulator. Контекстные изображения с именем comparison созданы ImageGen.

## Иконка в приложении

### Текущая «Шов / Студия»

В issue [#12](https://github.com/dapmoed/weeklywins/issues/12) утверждена иконка «Шов» в палитре «Студия». По запросу пользователя фоны светлого и тёмного вариантов установлены в чёрный цвет (`#000000`), цвета и геометрия знака сохранены. Исходные SVG находятся в [seam-studio](seam-studio/). Тонированный вариант использует подготовленный монохромный SVG-слой на прозрачном фоне, чтобы iOS могла применить выбранный оттенок. Остальные исходники доступны в [дизайн-комплекте issue](https://github.com/dapmoed/weeklywins/tree/0f6912a3d24d270f8f317c1adfc30ddda7c218ca/design/app-icon/assets/seam).

Проверено на домашнем экране iPhone 17 Pro Simulator с iOS 26.5:

- [Стандартное оформление с чёрным фоном](verification/weeklywins-seam-studio-black-light-simulator-2026-11-26.png)
- [Тёмное оформление с чёрным фоном](verification/weeklywins-seam-studio-black-dark-simulator-2026-11-26.png)
- [Однотонное оформление с системным оттенком](verification/weeklywins-seam-studio-black-tinted-simulator-2026-11-26.png)

### Предыдущие варианты

25 ноября 2026 года была подключена иконка «Закат»: алое солнце над двумя серыми полосами на тёмном фоне. [Векторный исходник](weeklywins-sunset.svg). Этот вариант заменён на «Шов / Студия» в текущем AppIcon.

22 ноября 2026 года пользователь утвердил плоскую иконку по макету с мятной W-волной, переплетённой с чёрной звуковой осцилляцией, и коралловой точкой на графитовом фоне. [Кроп утверждённого макета](flat-black-wave-reference-crop.png) сохранён как визуальный эталон. Установленный ресурс `WeeklyWins/Assets.xcassets/AppIcon.appiconset/AppIcon.png` (1024 × 1024) извлечён из этого изображения.

Предыдущая объёмная «Эхо C» была подключена в сборке 16. Каталог AppIcon выбран в project.yml и сгенерированном Xcode-проекте.

[Скриншот установленного WeeklyWins со сборкой 16](weeklywins-build-16-home-screen.png) получен непосредственно из iOS Simulator после удаления временных приложений просмотра.

[Домашний экран Simulator со сборкой 48](weeklywins-flat-black-wave-simulator-2026-11-22.png) подтверждает отображение иконки, повторяющей утверждённый макет, среди системных приложений.
