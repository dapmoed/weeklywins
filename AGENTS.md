# Инструкции для разработки WeeklyWins

## Утверждённый дизайн

Пользователь утвердил «Голосовую студию» с расположением A «Лента дня» и потребовал точного следования дизайну.

Перед изменением интерфейса прочитай `docs/design/approved-design.md`, просмотри `docs/design/layout-a-approved.png` и соответствующие экраны A01–A18 в `docs/design/layout-options.md`.

- Следуй утверждённым композиции, цветам, типографике, формам компонентов и переходам.
- Для экранов, представленных на PNG, изображение определяет внешний вид. Спецификация определяет поведение и дополнительные состояния.
- Для остальных экранов используй описание варианта A и общую визуальную систему.
- Изменения утверждённого дизайна предварительно согласовывай с пользователем.
- Перед завершением этапа интерфейса сравни фактические скриншоты симулятора с эталоном при сопоставимых данных и состоянии. Исправь обнаруженные расхождения и укажи оставшиеся непроверенные состояния.
- Проверяй крупный системный текст, длинные русские подписи, safe area и клавиатуру согласно спецификации.

## Рабочий процесс

- Работай в текущей папке проекта.
- Основные проверки выполняй на симуляторе. Физический iPhone используй при технической необходимости.
- После каждого завершённого этапа выполняй проверку, коммит и push.
- На время серии тестов на реальном iPhone включай тестовую сессию через `scripts/device-test-session.py begin`, чтобы после первой разблокировки экран оставался активным.
- Запускай физические тесты через `scripts/device-test-session.py run --command ...`. Обёртка возвращает WeeklyWins на передний план между запусками.
- Завершай тестовую сессию командой `end` после серии, перед паузой цели и при остановке работы. Проверяй подтверждение снятия удержания экрана. Инструкция находится в `docs/device-test-session.md`.
